# AI Website Chatbot

An AI-powered website chatbot built using automation workflows with the help of company's documentation to get specific and relevant results.

## Features
- Answers customer queries using company documentation 
- Works 24/7
- Schedules meetings automatically
- Sends notifications to sales team

## Tools Used
- n8n
- OpenAI API
- Google Sheets /Airtable
- Pinecone
- Chatwoot

## Workflow
1. User asks a question
2. AI searches from uploaded company information
3. Chatbot responds automatically
4. Qualified leads are identified
5. Meeting scheduling is triggered
